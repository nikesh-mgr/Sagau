# Core Features

## 1. Authentication System

### Features

- Email signup/login
- Phone signup/login
- JWT authentication
- Role selection:
  - Client
  - Worker

### Future

- Role switching
- OTP verification

---

# 2. Worker Profile System

Worker profiles include:

- profile picture
- bio/about
- location
- skills
- completed jobs
- trust score
- reviews/history
- uploaded documents

---

# 3. Job Posting System

Clients can:

- create jobs
- add title
- add description
- choose category
- add location

---

# 4. Application System

Workers can:

- browse jobs
- apply to jobs
- propose pricing
- send proposal message

Clients can:

- review applicants
- select workers

---

# 5. Agreement System

After worker selection:

- worker accepts/rejects
- client and worker decide:
  - final price
  - deadline

Platform stores agreement details.

---

# 6. Review & Trust System

After completion:

- both sides leave reviews

Includes:

- star rating
- written feedback

Trust score based on:

- completed jobs
- ratings
- reviews
- verification

---

# 7. Verification System

Users can upload:

- citizenship
- ID proof
- certificates

Admin manually verifies users.

Verified users receive:

- verified badge/tick

Verification is optional.

---

# 8. Admin Dashboard

Admin can:

- manage users
- verify documents
- monitor platform stats
- handle reports/disputes

---

# 9. Location System

MVP uses:

- manual location selection

Used for:

- filtering workers/jobs

No live GPS initially.

---

# 10. Monetization

## Initial Phase

- No internal payment system

## Later

- first 10 jobs free
- subscription OR 5% commission

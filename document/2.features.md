# Overview

The Sagau platform is built around a collection of interconnected modules that support the complete hiring lifecycle, from user registration to work completion and reputation building.

The system is divided into:

## Current MVP Features

Features implemented in Version 1.0.

## Future Features

Features planned for future releases.

---

# 2.1 Authentication System

## Purpose

Provides secure access to the platform and manages user identity.

---

## Features

### User Registration

Allows new users to create accounts.

Required Information:

- Full Name
- Email Address
- Password
- User Role

---

### User Login

Allows registered users to access their accounts securely.

---

### JWT Authentication

Uses JSON Web Tokens for:

- Secure Session Management
- User Identification
- Protected API Access

---

### Role-Based Authorization

Controls access based on user roles.

Roles include:

- Client
- Worker
- Admin

---

### Protected Routes

Prevents unauthorized access to sensitive resources.

Examples:

```text id="zv8i0z"
/api/jobs/create
/api/admin/users
/api/workers/profile
```

---

### Password Security

Passwords are:

- Salted
- Hashed
- Never stored in plain text

---

### Token Verification

Every protected request validates:

- User Identity
- User Role
- Token Expiration

---

# Authentication Workflow

```text id="1lbmmy"
Register
   ↓
Login
   ↓
JWT Generated
   ↓
Protected Access
   ↓
Authorized Operations
```

## Client Capabilities

Clients can publish new jobs.

---

### Edit Job

Clients can modify existing jobs before hiring.

---

### Delete Job

Clients can remove jobs when no longer needed.

---

### Update Job Status

Clients can update the lifecycle state of a job.

---

| Category        | Job Category          |

| Location        | Service Area          |

| Required Skills | Skills Needed         |

# 2.5 Agreement System

## Purpose

Acts as a digital work contract between client and worker.

The agreement defines responsibilities and tracks work progress.

---

## Agreement Contains

- Client Information
- Worker Information
- Job Information
- Timeline
- Deliverables
- Agreement Status

---

## Agreement States

### ACTIVE

Work is currently in progress.

---

### COMPLETED

Work has been successfully completed.

---

### CANCELLED

Agreement has been terminated.

---

# Agreement Lifecycle

```text id="q3kgn4"

   ↓
COMPLETED
```

OR

```text id="dd7rfd"
ACTIVE
   ↓
CANCELLED
```

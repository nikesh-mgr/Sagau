# 03. Core Features

---

# Overview

Sagau is built as a modular marketplace platform where each feature represents an independent business module.

Each module has a specific responsibility while working together to support the complete hiring lifecycle—from user registration to reputation building.

---

# 1. Authentication Module

## Purpose

Securely identify users and control access throughout the platform.

---

## Features

### Registration

Users can create an account using:

- Full Name
- Email
- Password
- Role

---

### Login

Users authenticate using:

- Email
- Password

Successful login returns:

- Access Token (JWT)
- User Information

---

### Logout

Terminates the current session.

---

### Password Security

Passwords are:

- Salted
- Hashed
- Never stored in plain text

---

### Role-Based Access Control (RBAC)

Supported roles:

- Client
- Worker
- Admin

Permissions are enforced through middleware.

---

## Future Improvements

- Refresh Tokens
- Email Verification
- Two-Factor Authentication (2FA)
- OAuth (Google, GitHub)

# 4. Worker Application Module

## Purpose

Allow workers to express interest in jobs.

---

## Features

Workers may submit:

- Proposal
- Estimated Cost
- Estimated Duration

---

## Application Rules

- One application per worker per job.
- Workers cannot apply to their own jobs.
- Closed jobs cannot receive applications.

---

## Application Status

```text
PENDING
 ↓
REVIEWED
 ↓
SHORTLISTED
 ↓
ACCEPTED

or

↓

REJECTED
```

---

## Future Improvements

- Proposal Templates
- Proposal Attachments
- Withdraw Application
- Application History

# Conclusion

The modular architecture of Sagau enables independent development, testing, and scaling of each feature while maintaining a consistent marketplace experience. This design supports future enhancements without requiring major changes to the existing system, making the platform maintainable and production-ready.

# 08. Frontend Architecture

---

# 1. Overview

The Sagau frontend is built using a modern, component-driven architecture with React. It is designed to be scalable, maintainable, and performant while providing separate experiences for visitors, clients, workers, and administrators.

### Goals

- Clean folder organization
- Reusable UI components
- Fast page loading
- Secure authentication
- Responsive design
- Easy feature expansion
- Production-ready codebase

---

# 2. Technology Stack

| Technology             | Purpose                 |

| React                  | User Interface          |
| React Router DOM       | Routing                 |
| Tailwind CSS           | Styling                 |

| React Hook Form        | Form Handling           |

# 7. Protected Routes

Routes requiring authentication

```text
/client/**

/worker/**

/admin/**
```

Rules

- User must be logged in.
- JWT must be valid.
- Correct role required.

---

# 8. Role-Based Routing

Client routes

```text
/client/*
```

Worker routes

```text
/worker/*
```

Admin routes

```text
/admin/*
```

Unauthorized users are redirected to

```text
/login
```

or

```text
/403
```

# Summary

The Sagau frontend architecture follows a modular, component-based structure with dedicated layouts, reusable components, centralized state management, and secure routing. This architecture provides a scalable foundation for building a production-ready marketplace while keeping the codebase maintainable and easy to extend.

## Recommended Additional Pages

For a production-ready marketplace, I also recommend including these pages:

| Route                   | Purpose                                         |
| ----------------------- | ----------------------------------------------- |
| `/search`               | Global search for jobs, workers, and categories |
| `/notifications`        | View all notifications                          |
| `/saved-jobs`           | Workers can save jobs                           |
| `/saved-workers`        | Clients can bookmark workers                    |
| `/profile`              | Logged-in user's profile                        |
| `/edit-profile`         | Update profile information                      |
| `/help-center`          | FAQs and support                                |
| `/contact`              | Contact the Sagau team                          |
| `/privacy-policy`       | Privacy policy                                  |
| `/terms-and-conditions` | Terms of service                                |
| `/404`                  | Page not found                                  |
| `/500`                  | Server error page                               |
| `/maintenance`          | Maintenance mode page                           |

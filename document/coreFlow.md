4. Core Working Flow
   Complete Marketplace Flow
   Step 1 — User Registration

User registers as:

Client
Worker

Authentication handled using JWT.

Step 2 — Profile Creation

Worker creates:

bio
skills
experience
portfolio
verification details

Client creates:

personal/business profile
Step 3 — Client Posts Job

Client submits:

title
description
budget
location
category
deadline

Job status becomes:

OPEN

Step 4 — Workers Apply

Workers can:

send proposals
submit expected pricing
explain qualifications

Application linked with:

Worker ID
Job ID
Step 5 — Client Reviews Applicants

Client compares:

profiles
ratings
skills
verification status
Step 6 — Worker Selection

Client selects one worker.

System actions:

job becomes ASSIGNED
agreement created automatically
Step 7 — Work Starts

Worker begins assigned task.

Job status becomes:

IN_PROGRESS

Step 8 — Work Completion

Client marks work completed.

Agreement status becomes:

COMPLETED

Step 9 — Review & Rating

Client submits:

rating
written review

Review contributes to:

reputation
trust score
future ranking system

# 5. User Roles and Permissions

---

# Overview

Sagau follows a Role-Based Access Control (RBAC) model where users are assigned specific roles. Each role has predefined permissions that determine which actions can be performed within the platform.

The system currently supports three primary user roles:

1. Client
2. Worker
3. Admin

This role-based architecture improves:

- Security
- Authorization Control
- System Management
- User Accountability

# 1. Client Role

## Description

Clients are users who require services or work to be completed by skilled workers.

They can be:

- Individuals
- Homeowners
- Businesses
- Startups
- Organizations

The primary responsibility of a client is to create job opportunities and hire suitable workers.

---

## Client Permissions

### Job Management

Clients can:

- Create Jobs
- Edit Jobs
- Delete Jobs
- View Posted Jobs
- Close Jobs

---

### Application Management

Clients can:

- View Applications
- Review Proposals
- Compare Applicants
- Shortlist Candidates

---

### Hiring Management

Clients can:

- Select Workers
- Hire Workers
- Create Agreements
- Track Work Progress

---

### Work Completion

Clients can:

- Approve Completed Work
- Request Revisions
- Mark Work as Completed

---

### Review System

Clients can:

- Submit Ratings
- Write Reviews
- Evaluate Worker Performance

---

## Client Access Summary

✓ Manage Jobs
✓ Review Applications

# 3. Admin Role

## Description

Admins are responsible for maintaining platform integrity, security, trust, and operational efficiency.

Admins have the highest level of access within the system.

---

## Admin Responsibilities

### Platform Management

Admins oversee the overall platform operation.

Responsibilities include:

- System Monitoring
- Platform Configuration
- Service Maintenance

---

### User Management

Admins can:

- View Users
- Suspend Accounts
- Block Users
- Remove Users
- Investigate Reports

---

### Worker Verification

Admins can:

- Review Verification Requests
- Approve Verification Documents
- Reject Verification Requests
- Monitor Verification Activity

---

### Content Moderation

Admins can:

- Review Jobs
- Remove Fraudulent Listings
- Remove Inappropriate Content
- Handle Abuse Reports

---

### Dispute Resolution

Admins can:

- Investigate Disputes
- Review Agreements
- Examine Evidence
- Make Final Decisions

---

### Analytics & Monitoring

Admins can monitor:

- Total Users
- Active Workers
- Active Clients
- Job Statistics
- Verification Requests
- Platform Growth Metrics

---

# Security Enforcement

Role permissions are enforced using JWT authentication and role-based middleware.

Example:

```javascript
authorize("admin");
authorize("worker");
authorize("client");
```

---

# Benefits of Role-Based Access Control

The RBAC model provides:

- Secure Access Control
- Better User Management
- Clear Responsibility Separation
- Reduced Unauthorized Access
- Easier System Maintenance
- Scalable Authorization Design

# Conclusion

Sagau's user management system is built around three core roles—Client, Worker, and Admin. Each role is assigned specific permissions and responsibilities, ensuring secure platform operations, efficient hiring workflows, and a trustworthy marketplace environment.

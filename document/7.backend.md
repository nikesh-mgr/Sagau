# 7. Backend Architecture Overview

---

# Backend Technology Stack

Sagau follows a modern RESTful backend architecture built using the MERN ecosystem.

## Core Technologies

### Runtime Environment

- Node.js

Provides the server-side JavaScript runtime responsible for handling API requests and business logic.

---

### Backend Framework

- Express.js

Handles:

- Routing
- Middleware
- Request Processing
- API Development

---

### Database

- MongoDB

A NoSQL database used for storing:

- Users
- Jobs
- Applications
- Agreements
- Reviews
- Notifications
- Verification Requests

---

### ODM

- Mongoose

Used for:

- Schema Design
- Data Validation
- Database Queries
- Relationships

---

### Authentication

- JWT (JSON Web Token)

Used for:

- Secure Login
- User Sessions
- Protected Routes
- Role Authorization

---

### Password Security

- bcryptjs

Used to hash and verify passwords.

---

### Environment Management

- dotenv

Stores sensitive information:

- Database URL
- JWT Secret
- Cloud Storage Keys

---

# Backend Architecture

```text
Client (React Frontend)
          │
          ▼
      API Routes
          │
          ▼
      Middleware
          │
          ▼
      Controllers
          │
          ▼
      Services Layer
          │
          ▼
       Mongoose
          │
          ▼
```

# REST API Architecture

All APIs follow:

```text
/api/{resource}
```

Example:

```text
/api/jobs
/api/workers
/api/auth
```

---

# Authentication APIs

## Register User

```http
POST /api/auth/register
```

Creates new user account.

### Request Body

```json
{
  "name": "John",
  "email": "john@gmail.com",
  "password": "123456",
  "role": "worker"
}
```

---

## Login

```http
POST /api/auth/login
```

Returns JWT Token.

---

## Current User

```http
GET /api/auth/me
```

Returns logged-in user information.

---

## Logout

```http
POST /api/auth/logout
```

Invalidates current session.

# Security Layer

## Authentication Middleware

Responsible for:

- JWT Validation
- User Identification
- Session Verification

---

## Authorization Middleware

Controls access based on roles.

### Roles

- Client
- Worker
- Admin

Example:

```text
Only Admin → Verification Approval
Only Worker → Apply Job
Only Client → Post Job
```

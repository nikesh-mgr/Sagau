# 3. System Architecture

---

# Overview

Sagau follows a modern three-tier architecture that separates the presentation layer, business logic layer, and data layer.

This architecture improves:

- Scalability
- Maintainability
- Security
- Performance
- Future expansion

The system is designed as a RESTful web application where the frontend communicates with backend APIs, and the backend manages business logic, authentication, and database operations.

# Backend Design Principles

## Stateless Architecture

Each request contains all information required to process it.

Benefits:

- Easy Scaling
- Better Performance
- Load Balancer Friendly

---

## RESTful API Design

All operations are exposed through REST APIs.

Examples:

```http
GET    /api/jobs
POST   /api/jobs
PUT    /api/jobs/:jobId
DELETE /api/jobs/:jobId
```

Benefits:

- Standardized
- Easy Integration
- Frontend Independent

---

## Role-Based Access Control (RBAC)

Users receive permissions based on roles.

### Roles

#### Client

Permissions:

- Post Jobs
- Hire Workers
- Review Workers

#### Worker

Permissions:

- Apply Jobs
- Manage Profile
- Upload Documents

#### Admin

Permissions:

- Manage Users
- Approve Verification
- View Analytics
- Resolve Disputes

---

## Modular Architecture

Features are organized into independent modules.

### Advantages

- Easy Maintenance
- Code Reusability
- Team Collaboration
- Better Testing
